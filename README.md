# Sudoeste Armeria

Catálogo institucional responsivo da Sudoeste Armeria, localizada em Santo Antônio do Sudoeste - PR.

## Estrutura

- `index.html`: página principal
- `styles.css`: estilos responsivos
- `script.js`: catálogo, filtros e detalhes
- `assets/`: imagens dos produtos

## Visualização

Abra `index.html` no navegador ou use um servidor HTTP estático.
